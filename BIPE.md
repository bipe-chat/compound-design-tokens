# Bipe tokens fork

Fork of element-hq/compound-design-tokens (AGPL-3.0) at `v11.3.1`. It re-themes Compound for Bipe (ADR 0054) on iOS, Android and web.

## Changes from upstream

1. **New base family `acai`** (and `alpha.acai`) in all four theme files (`theme-light`, `theme-dark`, `theme-light-hc`, `theme-dark-hc`). Generated by `bipe/acai-ramp.mjs`: OKLCH hue 330, each step solved to the **same WCAG contrast target as Compound's green ramp** in that theme, so Compound's accessibility guarantees hold.
2. **Accent semantic tokens point at `acai`, two steps deeper than green** (green 900 becomes açaí 1100, 8.0:1). This gives the brand plum in light (`#80307B`) and soft pink in dark (`#D993D2`). See bipe/docs/design/identity.md.
   - Shifted: `text.action.accent`, `text.badge.accent`, `bg.accent.rest|hovered|pressed`, `border.accent.primary`, `icon.accent.primary|tertiary`, `gradient.action.*` (send and super buttons).
   - Same step: `bg.accent.subtle`, `bg.badge.accent`, `border.accent.subtle`, `bg.accent.selected` and `gradient.subtle.*` (alpha).
3. **`success.*` stays green.** Verified states use açaí, not green.
4. **Trust semantic tokens** (`color.{text,icon,border}.trust.{verified,caution,danger,neutral}`, `color.bg.trust.verified.{solid,subtle}`, `color.bg.trust.{caution,danger,neutral}.subtle`) in `theme-semantics.json`. Text and icons use step 1100 of `acai`, `yellow` (amber), `red` and `gray`: 8.0:1 on the default background and 7.4:1 or more on the `.subtle` card backgrounds (AAA) in light and dark, and 10:1 or more in high contrast. Caution uses `yellow`, not `orange`: Compound's orange 900 and red 900 have the same luminance and the same hue family. See bipe/docs/design/trust-ui.md.

## Single source for colour values

This fork is the only source of açaí values. Docs, the iOS `accent-color.colorset` and other consumers reference fork steps (brand plum = `acai.1100`: `#80307B` light, `#D993D2` dark). They do not keep a second ramp.

## Build

pnpm 12 is pinned upstream. Do not let pnpm auto-download it. Run the build tools directly:

```bash
./node_modules/.bin/vite build && ./node_modules/.bin/tsx ./build.ts
```

Dependencies were installed with pnpm 10 from the second YAML document of `pnpm-lock.yaml` (the first pins pnpm itself); the committed lockfile stays upstream's.

Regenerate the ramp after an upstream update: `git checkout upstream/main -- tokens/`, run `node bipe/acai-ramp.mjs`, re-apply the semantic remap, then build.

## Consumers

- bipe-ios `compound-ios/Package.swift` points at this repo by local path (`../../bipe-tokens`), because the repo is private until launch.
- Android: not yet.

## Traps

- Never run `pnpm` here: upstream pins pnpm 12 in `packageManager` and pnpm auto-downloads it, even with `manage-package-manager-versions=false` on some commands.
- The GitHub repo must stay named `compound-design-tokens`: SwiftPM names a mirrored package after the mirror repo, and Element packages reference `compound-design-tokens`.
