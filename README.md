## ✅ Supported platforms

Design tokens support light and dark themes, as well as a mode with higher contrast.
Tokens are exported to three platforms

- **Web**
  - CSS properties
  - JavaScript
- **iOS**
  - Swift
- **Android**
  - Kotlin
