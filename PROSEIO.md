# Proseio tokens fork

Fork of element-hq/compound-design-tokens (AGPL-3.0) at `v11.3.1`. It re-themes Compound for Proseio on iOS, Android and web.

## Changes from upstream

1. **New base family `acai`** (and `alpha.acai`) in all four theme files (`theme-light`, `theme-dark`, `theme-light-hc`, `theme-dark-hc`). Generated by `proseio/acai-ramp.mjs`: OKLCH hue 330, each step solved to the **same WCAG contrast target as Compound's green ramp** in that theme, so Compound's accessibility guarantees hold.
2. **Accent semantic tokens point at `acai`, two steps deeper than green** (green 900 becomes açaí 1100, 8.0:1). This gives the brand plum in light (`#80307B`) and soft pink in dark (`#D993D2`). See proseio/docs/design/identity.md.
   - Shifted: `text.action.accent`, `text.badge.accent`, `bg.accent.rest|hovered|pressed`, `border.accent.primary`, `icon.accent.primary|tertiary`, `gradient.action.*` (send and super buttons).
   - Same step: `bg.accent.subtle`, `bg.badge.accent`, `border.accent.subtle`, `bg.accent.selected` and `gradient.subtle.*` (alpha).
3. **`success.*` stays green.** Verified states use açaí, not green.

## Build

pnpm 12 is pinned upstream. Do not let pnpm auto-download it. Run the build tools directly:

```bash
./node_modules/.bin/vite build && ./node_modules/.bin/tsx ./build.ts
```

Dependencies were installed with pnpm 10 from the second YAML document of `pnpm-lock.yaml` (the first pins pnpm itself); the committed lockfile stays upstream's.

Regenerate the ramp after an upstream update: `git checkout upstream/main -- tokens/`, run `node proseio/acai-ramp.mjs`, re-apply the semantic remap, then build.
